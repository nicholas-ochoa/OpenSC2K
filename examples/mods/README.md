# Example mods

JavaScript mods for OpenSC2K. Each folder is one mod, with an `info.json`
file. To use a mod, copy its folder into the `mods` folder of the OpenSC2K
data folder. Then restart the game, or select **Reload Mods** in the Mods tab
of Settings. [Mods](../../docs/mods.md) describes the mod folder, and
[Scripting](../../docs/scripting.md#example-mods) describes each mod and the
whole API.

The `scripting_examples_test` validation test loads each mod.
