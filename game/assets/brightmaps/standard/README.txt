Standard building brightmaps

Authored RGBA light masks for the standard Windows graphics set.
RGB stores light color; alpha stores its strength. These files contain only
light masks. Original game sprites, palettes and comparison images are not included.

The catalog contains dimensions and SHA-256 hashes of decoded source indices.
Only matching artwork receives a mask. Empty templates are omitted.
An empty custom brightmap folder uses this set; a custom folder replaces it.

Authored and revised with AI assistance for the Visual Enhancements package,
including pixel-level review by Daniel Gimmer. Distributed under the repository
license.
