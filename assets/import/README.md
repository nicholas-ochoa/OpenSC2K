# Local game assets

OpenSC2K currently needs two files from a legally owned Windows 95 copy of
SimCity 2000 Special Edition:

- `LARGE.DAT`
- `PAL_MSTR.BMP`

Copy both files into this directory before starting the development server.
Common locations in a Windows 95 installation are:

- `SC2K/DATA/LARGE.DAT`
- `SC2K/BITMAPS/PAL_MSTR.BMP`

The files are proprietary and intentionally ignored by Git. Do not commit or
redistribute them.
